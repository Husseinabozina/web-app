# MADAR Group — Saudi Corporate Website Concept

Interactive bilingual corporate website concept for a **fictional Saudi multi-sector holding company**. Designed to help pitch a premium corporate site redesign to a prospective client.

> Design concept only. Names, portfolio projects, sectors and editorial content are illustrative. This is **not** a WordPress implementation and the quote request form **does not send information**.

## Features

- Arabic-first RTL experience and English LTR toggle (saved locally)
- Editorial architectural homepage and responsive navigation
- About, Business Sectors, Services, Projects, Clients & Partners, Insights, Contact
- Sector detail and project case-study screens
- Real client-side project category filtering
- Interactive RFQ form with built-in validation and honest demo confirmation
- Reduced-motion accessibility support and mobile layout
- Standalone static HTML, CSS and JavaScript: no install or build needed

## Open

Open [index.html](index.html) in a browser or serve it with any static HTTP server.

### Publish with GitHub Pages

A publishing workflow is committed at [pages.yml](.github/workflows/pages.yml). In **Settings → Pages → Build and deployment**, select **GitHub Actions** to enable the site if GitHub Pages has not already been configured. The expected Pages URL once deployment succeeds is:

`https://husseinabozina.github.io/web-app/`

Don't treat that address as live until GitHub reports a successful Pages deployment.

## Creative direction

- Original fictional group identity: MADAR
- Editorial architecture-inspired layouts influenced by the type of premium corporate presentation seen on Turner Construction, without copying their intellectual property.
- Stock architectural photography served from Unsplash, used illustratively.
- Color palette: deep green, warm ivory, muted copper.

## Production implementation

The prospect requested a WordPress website. This project is **a clickable design prototype only** to align on visual direction before any contractual WordPress implementation, client content migration, form email integration, SEO deployment, security configuration or CMS setup.
